名称
游戏算法公式
描述伤害/护甲吸收/命中/躲避/格挡公式、近战物理/转换穿刺暴击减伤机制
数据文件data\database\records\game\combatequations.dbr
武器白字物理伤害公式(physicalDamageDV * ((strengthDV/500)+1)) + (strengthDV*0.04)
武器白字转换穿刺伤害公式(((pierceDamageDV / ((strengthDV/500)+1)) * ((strengthDV/2000)+1)) * ((dexterityDV/400)+1)) + (dexterityDV*0.03)
非武器白字物理伤害公式physicalDamageDV * ((strengthDV/650)+1)
穿刺伤害公式pierceDamageDV * ((dexterityDV/1000) +1)
撕裂伤害公式physicalDamageDV * ((intelligenceDV / 500) +1)
火焰/冰冷/闪电/活力伤害公式(elementalDamageDV * ((intelligenceDV / 650) + 1)) + (intelligenceDV*0.025)
燃烧/冰冻/电击/衰老伤害公式elementalDamageDV * ((intelligenceDV / 500) + 1)
即时毒素伤害公式poisonDamageDV * ((dexterityDV / 500) + 1)
持续毒素伤害公式poisonDamageDV * ((dexterityDV / 500) + 1)
流血伤害公式bleedingDamageDV * ((dexterityDV / 500) + 1)
生命吸取公式lifeLeachDamageDV * (1 + (characterLevelDV / 40))
法力吸取公式manaLeachDamageDV * (1 + (characterLevelDV / 40))
反击伤害公式retaliationDamageDV * (1+ ((characterLevelDV^2) / 1250))
物理伤害过小护甲公式(sumProtectionDV * (1 - sumAbsorptionDV)) + (physicalDamageDV - sumProtectionDV)
物理伤害过大护甲公式physicalDamageDV * (1 - sumAbsorptionDV)
战斗能力公式(offensiveAbilityDV + ((dexterityDV * 1) + bonusDV)) * (1 + (offensiveAbilityModifierDV / 100))
防御能力公式(defensiveAbilityDV + ((dexterityDV * 1) + bonusDV)) * (1 + (defensiveAbilityModifierDV / 100))
攻防比命中率公式
（攻防比命中率=1-攻防比失误率）		(100 * (0.88^((100 + (defensiveAbilityDV - offensiveAbilityDV)) / 100))) +10
盾牌近战格挡率公式(blockChanceDV + blockChanceModifierDV) - ((probabilityToHitDV - 100) * 0.5)
盾牌远程格挡率公式(blockChanceDV + blockChanceModifierDV) * ((dexterityDV / 1000) + 1)
盾牌格挡大伤害公式damageDV - (shieldDefenseDV * (( 100 - shieldAbsorptionDV) / 100))
盾牌格挡小伤害公式damageDV * ((100 - shieldAbsorptionDV) / 100 )
