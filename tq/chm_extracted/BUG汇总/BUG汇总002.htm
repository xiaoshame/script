Bug Code 说            明
BUG_GUI_001(F) 三种难度下的遗物“阿努比斯的愤怒”（Anubis' Wrath）在背包中的显示均有错误（超出格子边线）。现修正。
BUG_GUI_002(F) 唯一锤类武器“影子国王的王杖”（Scepter of the Shadow King）在背包中的显示错误（短了半格）。现修正。
BUG_GUI_003 每次进入游戏时，对于所有宠物召唤类技能，在技能页面中显示的宠物属性仅仅是技能本身等级（玩家在该技能上投入的技能点数）下的属性，而不是由装备或者祭坛提高等级后的属性。该BUG仅影响技能页面的显示，并不影响召唤出的宠物的真实属性。只要改变一次技能本身等级，即使立刻取消改变，显示也将恢复正常（能够正确反映出装备或祭坛提升等级的影响），并且只要没有退回主菜单，就会一直保持正确显示。该BUG属于代码错误，尚无法修正。所涉及的技能有：
    大地专精中的“地心守卫”（Summon Core Dweller）；
    盗贼专精中的“陷阱设置”（Lay Trap）；
    风暴专精中的“召唤风暴精灵”（Summon Wisp）；
    梦幻之境中的“召唤梦魔”（Summon Nightmare）；
    狩猎专精中的“引诱”（Monster Lure）；
    死灵专精中的“尸王召唤”（Summon Liche King）和“召唤外界生物”（Summon Outsider）；
    战斗专精中的“战斗军旗”（Battle Standard）和“祖传号角”（Ancestral Horn）；
    自然专精中的“石楠木环”（Briar Ward）、“召唤精灵狼”（Call of the Wild）和“召唤仙女”（Sylvan Nymph）。
BUG_GUI_004 在很多情况下，在人物属性界面上显示的“综合防御值”（Combined Armor）以及通过在其上鼠标悬停所看到的各部位护甲都是错误的，例如不能正确反映出诸如镶嵌物或者套装奖励所提供的护甲或者护甲加成等等。而且“综合防御值”本身没有任何意义，因为在每次受到攻击的时候，只有选定部位的护甲值起作用。
真正的各部位护甲值计算遵循以下规律：
    1、防具本身的护甲值仅对防具所在部位有效；
    2、防具所附带的词缀上的护甲值仅对防具所在部位有效；
    3、其它一切来源（包括来源于镶嵌在某个部位防具上的镶嵌物）的护甲值均对所有部位有效，即：相当于在每个部位的护甲值上附加了该值；
    4、一切护甲值加成均对所有部位的护甲值有效。
BUG_GUI_005 有些装备根据玩家角色性别的不同，其外观是不同的，因此有两套用来在背包里显示的图象，分别用于男性和女性角色。但在资料片新增的、由商队（Caravan）提供的储物箱和公共空间里，并未就玩家的性别进行显示上的区分，而是统一使用了对应男性角色的图象。这导致女性角色在将该装备放入储物箱和公共空间时，装备的图象会突然发生变化。所涉及到的装备有 （均包括所有难度下的同名装备）：
    特殊战系铠甲“护卫的胸甲”（Guard's Cuirass）；
    特绿战系铠甲“哨兵胸甲”（Sentinel's Cuirass）；
    特殊法系铠甲“恩普萨胸衣”（Empusa Corselet）；
    特绿法系铠甲“黑暗女王之胸衣”（The Night Mistress's Corselet）；
BUG_GUI_006 玩家的所有抗性均以80%为上限，但在人物属性界面中，副抗性却未按此显示。
