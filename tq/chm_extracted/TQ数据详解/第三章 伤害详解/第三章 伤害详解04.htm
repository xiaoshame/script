第五节 主动型属性伤害

　　本类伤害并不会造成被攻击方生命值的降低，但会导致其它属性的降低（例如抗性、速度等），或者直接降低对方的伤害输出。这种降低并不是永久的，而是只在一定时间内有效，因此，本类伤害必然都存在一个次伤害数值——持续时间。

　　本类伤害中，只有一部分种类的伤害存在对应的伤害加成。加成形式有两种，一种是只增加主伤害数值，另一种在增加主伤害数值的基础上，还增加次伤害数值（持续时间）。增加持续时间的这部分称为持续时间加成。

　　对于本类伤害，被攻击方均无相应的持续时间降低。

　　本类伤害并不是直接实施到被攻击方的属性上的，而是作为被攻击方的当前状态之一被记录下来（只要还在持续时间之内），每当被攻击方需要使用相关属性时（例如需要用到抗性、速度，或者进行伤害输出），它就会参与运算。详细的实施方式见第二章。各种属性的计算公式见第五章。

　　本类共有13种。对应加成有5种。

　　1、　　减慢攻击

　　基础伤害形式：

　　界面中文：XX% 减慢攻击 持续 Y.Y 秒

　　界面英文：XX% Slower Attack for Y.Y Seconds

　　主伤害数值：减慢百分比，即界面形式中百分号前的“XX”。

　　减慢攻击加成形式：

　　界面中文：+XX% 减慢攻击

　　+XX% 减慢攻击 增加 +YY% 的持续时间

　　界面英文：+XX% Slow Attack

　　+XX% Slow Attack with +YY% Improved Duration

　　伤害输出计算：

　　令：A = 基础伤害主伤害数值 * (1 + 减慢攻击加成%)

　　主伤害数值 = A * (1 + 特定种族伤害加成%) * (1 - 百分比降低全部伤害%) - 降低全部伤害

　　持续时间 = 基础伤害持续时间 * (1 + 减慢攻击持续时间加成%)

　　被攻击方有效抗性：缓慢抗性。

　　伤害实施：主伤害数值影响被攻击方的攻击速度。

　　2、　　减慢移动

　　基础伤害形式：

　　界面中文：XX% 减慢速度 持续 Y.Y 秒

　　界面英文：XX% Slower Movement for Y.Y Seconds

　　主伤害数值：减慢百分比，即界面形式中百分号前的“XX”。

　　注意：

　　“减慢移动”与“减慢全部速度”的基础伤害形式在中文界面上无法区分。

　　减慢移动加成形式：

　　界面中文：+XX% 减慢速度

　　+XX% 减慢速度 增加 +YY% 的持续时间

　　界面英文：+XX% Slow Movement

　　+XX% Slow Movement with +YY% Improved Duration

　　伤害输出计算：

　　令：A = 基础伤害主伤害数值 * (1 + 减慢移动加成%)

　　持续时间 = 基础伤害持续时间 * (1 + 减慢移动持续时间加成%)

　　被攻击方有效抗性：缓慢抗性。

　　伤害实施：主伤害数值影响被攻击方的移动速度。

　　3、　　减慢全部速度

　　基础伤害形式：

　　界面中文：XX% 减慢速度 持续 Y.Y 秒

　　界面英文：XX% Slowed for Y.Y Seconds

　　主伤害数值：减慢百分比，即界面形式中百分号前的“XX”。

　　注意：

　　“减慢全部速度”与“减慢移动”的基础伤害形式在中文界面上无法区分。

　　相应加成：无。

　　伤害输出计算：

　　主伤害数值 = 基础伤害主伤害数值 * (1 + 特定种族伤害加成%) * (1 - 百分比降低全部伤害%) - 降低全部伤害

　　持续时间 = 基础伤害持续时间

　　被攻击方有效抗性：缓慢抗性。

　　伤害实施：主伤害数值影响被攻击方的攻击速度、移动速度和施法速度。

　　4、　　降低战斗能力

　　基础伤害形式：

　　界面中文：XX 降低战斗能力 持续 Y.Y 秒

　　界面英文：XX Reduced Offensive Ability for Y.Y Seconds

　　主伤害数值：战斗能力的降低值，即界面形式中的“XX”。

　　降低战斗能力加成形式：

　　界面中文：+XX% 战斗能力

　　+XX% 战斗能力 增加 +YY% 的持续时间

　　界面英文：+XX% Offensive Ability

　　+XX% Offensive Ability with +YY% Improved Duration

　　注意：

　　无持续时间加成部分时，与增加自身战斗能力的加成在界面上无法区分。在原始游戏中，“降低战斗能力加成”基本不出现。

　　伤害输出计算：

　　令：A = 基础伤害主伤害数值 * (1 + 降低战斗能力加成%)

　　持续时间 = 基础伤害持续时间 * (1 + 降低战斗能力持续时间加成%)

　　被攻击方有效抗性：无。

　　伤害实施：主伤害数值影响被攻击方的战斗能力。

　　降低物理伤害加成

　　界面中文：+XX% 减少物理伤害

　　+XX% 减少物理伤害 增加 +YY% 的持续时间

　　界面英文：+XX% Reduced Physical Damage

　　+XX% Reduced Physical Damage with +YY% Improved Duration

　　7、　　降低护甲

　　基础伤害形式：

　　界面英文：XX Reduced Armor for Y.Y Seconds

　　持续时间 = 基础伤害持续时间

　　被攻击方有效抗性：无。

　　伤害实施：主伤害数值影响被攻击方的护甲值。被攻击方的所有部位的护甲值均会受到相同的影响。

　　8、　　降低全部伤害

　　基础伤害形式：

　　界面中文：XX 降低伤害 持续 Y.Y 秒

　　界面英文：XX Reduced Damage for Y.Y Seconds

　　主伤害数值：伤害的降低值，即界面形式中的“XX”。

　　相应加成：无。

　　伤害输出计算：

　　主伤害数值 = 基础伤害主伤害数值 * (1 + 特定种族伤害加成%) * (1 - 百分比降低全部伤害%) - 降低全部伤害

　　持续时间 = 基础伤害持续时间

　　注意：

　　上述第一式中，等号右侧的“降低全部伤害”是指攻击方在本次攻击发起前所受到的、来自敌方的“降低全部伤害”伤害，并且攻击方在发动攻击时，仍处于该伤害的持续时间之内。这与本次攻击中发动的“降低全部伤害”伤害不是一回事。

　　被攻击方有效抗性：无。

　　伤害实施：

　　主伤害数值降低其后被攻击方的伤害输出。被攻击方除“额外伤害”和“特定种族伤害”之外的所有主动型伤害的伤害输出均受其影响。

　　12、　　百分比攻击失误

　　基础伤害形式：

　　界面中文：XX% 机率发动攻击 持续 Y.Y 秒

　　界面英文：XX% Chance to Fumble attacks for Y.Y Seconds

　　主伤害数值：攻击失误的百分比，即界面形式中百分号前的“XX”。

　　相应加成：无。

　　伤害输出计算：

　　主伤害数值 = 基础伤害主伤害数值 * (1 + 特定种族伤害加成%) * (1 - 百分比降低全部伤害%) - 降低全部伤害

　　持续时间 = 基础伤害持续时间

　　被攻击方有效抗性：无。

　　伤害实施：

　　在此后的持续时间内，导致被攻击方所发动的所有近战攻击有一定几率失误，所有投射攻击（包括远程攻击和投射类技能攻击）有一定几率偏离目标（与目标中心偏离一定角度）。主伤害数值即这个失误率。对于近战攻击，攻击失误不算做攻击失败，因此仍然会引发反击或反弹。近战攻击失误的判定在躲避检定阶段，一旦近战攻击失误，则不会受到任何伤害；而对于远程或投射攻击，一旦投射偏离目标（没有射中），则算做攻击失败，不会引发反弹。不过，即使在偏离目标的情况下，主动凑到投射物上、或者距离投射发起者太近，或者处于投射物爆炸的有效范围内，还是会被射中和受到伤害的，因此主伤害数值并不表示“不被对方射中”的几率。

　　13、　　百分比投射失误

　　基础伤害形式：

　　界面中文：XX% 机率降低准确率 持续 Y.Y 秒

　　界面英文：XX% Chance of Impaired Aim for Y.Y Seconds

　　主伤害数值：投射失误的百分比，即界面形式中百分号前的“XX”。

　　相应加成：无。

　　伤害输出计算：

　　主伤害数值 = 基础伤害主伤害数值 * (1 + 特定种族伤害加成%) * (1 - 百分比降低全部伤害%) - 降低全部伤害

　　持续时间 = 基础伤害持续时间

　　被攻击方有效抗性：无。

　　伤害实施：该伤害是“百分比攻击失误”的简化版，只对远程攻击和投射攻击有效，效果与“百分比攻击失误”相同。
