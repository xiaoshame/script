第九节 反击型持续杀伤伤害

　　与主动型持续杀伤伤害类似，不过只能被反击发动。

　　所有这类伤害的主伤害数值都是每秒伤害值，而不是界面上显示的总伤害值（每秒伤害值 = 总伤害值 / 持续时间）。所有这类伤害的次伤害数值都是持续时间。

　　注意：

　　当持续时间为一秒时，持续时间部分：“在Y.Y秒内”（over Y.Y Seconds）在界面上会被写成“每秒”（per Second）。

　　所有这类伤害都有一个唯一的相应加成。但这些加成在游戏界面里均没有正确的文字描述，显然在原始游戏中不可能被玩家所拥有，但某些怪物可能会有其中某些加成，并且有效。如果自编地图并给玩家也设置了这些加成的话，界面上将显示诸如“TagNotFound:”之类的错误信息，但并不影响其加成效果。

　　本类加成分为增加主伤害数值和增加次伤害数值（持续时间）两部分，增加持续时间的部分称为持续时间加成。

　　本类伤害的实施方式见第二章。

　　本类共有7种。对应加成也是7种。

　　1、　　撕裂反击

　　基础伤害形式：

　　界面中文：XX 撕裂伤害反击在Y.Y秒内

　　界面英文：XX Wound Retaliation over Y.Y Seconds

　　相应加成：撕裂反击加成。

　　伤害输出计算：

　　主伤害数值 = 基础伤害主伤害数值 * (1 + 撕裂反击加成%)

　　持续时间 = 基础伤害持续时间 * (1 + 撕裂反击持续时间加成%)

　　被攻击方有效抗性：物理抗性。

　　被攻击方有效持续时间降低：撕裂持续时间降低。

　　延迟实施阶段等价主动型伤害种类：撕裂伤害。

　　注意：

　　虽然“撕裂伤害”仅在技能中有效，但“撕裂反击”却并不限于技能，在任何装备上也同样有效。

　　不是界面上写着“+XX% 冰冻反击”（+XX% Frostburn Retaliation）的那个。

　　主伤害数值 = 基础伤害主伤害数值 * (1 + 冰冻反击加成%)

　　持续时间 = 基础伤害持续时间 * (1 + 冰冻反击持续时间加成%)
