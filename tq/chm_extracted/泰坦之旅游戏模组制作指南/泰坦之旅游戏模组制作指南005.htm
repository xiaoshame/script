范例4：任务
　　范例4：任务

　　我们已经学会了建立世界、修改地形、设置敌人，但主角除了打怪物取得金钱与经验值之外还有什么乐趣？答案就是任务(quests)。任务档案(quest file)可以帮

　　助游戏控制事件流程而且可以触发各种任务事件。触发(Trigger)可以被设置在任何东西上，如：打开门、杀死敌人、得到技能点数。

　　举个例子：我们正要去解一个任务，任务内容是”杀死正在威胁村民的怪物”。一开始主角要跟村民讲话，村民会要求主角去杀死怪物，主角找到怪物并杀了它，主角回去跟村民讲话，村民会给主角报偿。这个任务和所有相关的资料库纪录早已经存在，我们所要做的就是在地图上设置任务所需要的物件，当玩家进入游戏后就可以执行这个任务。

　　4.0.1 检查环境

　　1)打开Editor编辑器。

　　2)选择mod ’Tutorial04’并开启’Tutorial-Quest_Objects.wrl’。

　　现在我们有一个世界，里面有不错的地形和一些装饰品，最重要的是有一个任务所需要的任务物件(quest object)，这个任务物件就是村民，这个村民是一个站在房屋旁边的胖老头。但是，现在我们还缺少任务中需要的另一个重要的物件，那就是村民要我们去杀的怪物。

　　4.0.2 设置任务物件

　　此范例已经内建一个’Tutorial-Quest_Satyr’物件，它跟’am_peltast_02’物件是一样的东西，但是在此范例中，它是完成任务所必需的敌人物件：Quest Satyr。

　　1)读取'custommaps\Tutorial04\source\Tutorial-Quest_Objects_Terrain.wrl'。

　　2)选择物件设置工具(Object Placement Tool)。

　　3)展开”Monsters”目录，选择”tutorial-quest_satyr”。

　　所有标准的Titan Quest资产都放在”records”目录底下。当你创造自己的资料纪录时，这此资料库纪录会出现在你所指定的资料夹底下；当你汇入(import)纪录时，你应该将这些纪录移到你自己的资料夹中，否则它会出现在”records”中的某处。

　　4)将’Tutorial-Quest_Satyr’放在到地图中。

　　你可以随意放置这个怪物，你只要记住此任务的事件触发就在这些特定的物件上。

　　4.0.3 建立并储存地图

　　编辑完成后，别忘了建立并储存你的地图

　　1)重建所有的路网和地图(如果不知道怎么做，请回去看1.5小节)。

　　2)点按File -> Save All。

　　3)打开Art Manager

　　4)建立’Tutorial-Quest_Objects.map’。

　　5)到游戏中试玩你的地图。

　　译：此范例中，打开4.0.1节的’Tutorial-Quest_Objects.wrl’后，如果你没有看到任务所需的村民；在4.0.2节中，也找不到’Monsters-> tutorial-quest_satyr’。请到ArtManager中，在选单中打开’mod -> Select -> Tutorial04’，选择DataBase标签页，按下Monsters资料夹，点选右边视窗出现的’ tutorial-quest_satyr.dbr’，点滑鼠按右键选择’Build’；NPCs中的’Tutorial-Quest_Villager.dbr’也是点按右键选择’Build’。到Editor中打开范例就会看到了。
