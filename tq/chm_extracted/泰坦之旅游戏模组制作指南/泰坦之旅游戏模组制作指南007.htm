范例6：地牢和网格
　　范例6：地牢和网格

　　到目前为止，我们所介绍的功能都是在户外环境使用的。Titan Quest还有另一种游戏环境就是网格(grid)，网格是设置地板与墙壁的地基，它适合用在户内或是地牢类型的平面区域。

　　网格有三个主要的元件：

　　地板(floor)、就是玩家可以在上面行走的区域

　　墙壁(walls)、可以用来制作迷宫

　　特征(features)。是地牢的另一种观点，特征可以跟地板或墙壁结合在一起，特征通常会有入口，入口可以用来连接不同的区域，后面会介绍。 　　

　　6.0.1检查环境

　　1)打开Editor编辑器

　　2)选择mod ‘Tutorial06’。

　　3)在Editor Mode中打开’ Tutorial-Dungeon_Crawl_Grid.lvl’，你会看到一个地牢，里面已建置了地板和墙壁。

　　6.1网格系统

　　6.1.1选择系统

　　1)选择网格编辑工具(grid edit tool)。

　　你会看到画面中出现紫色背景的网格，这代表网格平面区域的范围。地板(floor)和墙壁(walls)只能画在这个网格平面区域的范围内。 要设计网格的第一个步骤就是选择一个网格系统(system)。一个网格系统就是一个布景套件，每个网格系统中都有不同的地板、墙壁、特征样式(译：就像Windows的布景主题一样，每个布景主题中都有不同的背景图案、滑鼠指标图示、视窗样式等)。现在让我们来改变这个地牢的网格系统。

　　2)点按网格类型视窗(Grid Types Pane)中System栏位旁的’…’图示。

　　3)选择Records -> Underground -> Egypt -> EgyptCrypt.dbr。 这个地牢的的外观会立刻改变。 　　

　　6.2网格的操作

　　6.2.1画地板

　　我们先来画地板，在网格类型视窗(Grid Types Pane)中有一个Floor选取视窗。

　　1)在Floor选取视窗中选择’Floor’。 当你要清除地板时，你就要选择’ No Floor’。

　　2)点按滑鼠左键并移动就可以在网格上画出地板。

　　6.2.2 画墙壁

　　画墙壁跟画地板很像。在网格类型视窗(Grid Types Pane)中有一个Walls选视窗。

　　1)在Walls选取视窗中选择’Wall’。

　　当你要清除墙壁时，你就要选择’ No Wall’。

　　2)点按滑鼠左键并移动就可以在网格上画出墙壁。

　　6.2.3 画特征

　　特征就是门。网格类型视窗(Grid Types Pane)中有一个Features选取视窗。

　　1)在Features选取视窗中选择’ Dng_Egypt01_Base_EntranceG_Int01’。

　　2)点按滑鼠左键就可以在网格上画出特征。(译：方向键左、右可以调整方向)。

　　6.2.4 注意

　　如果你要建立多楼层的地牢，请使用楼梯(staircase)。

　　6.3完成你的网格世界

　　6.3.1 在网格上设置物件 物件(object)也可以设置在网格上。

　　1)选择物件设置工具(Object Placement Tool)。

　　2)在目录视窗(Directory Pane)中选择一个物件。

　　3)在网格中点按滑鼠左键就可以设置该物件。

　　6.3建置你的网格世界

　　网格世界的建置跟地形世界的建置方法相同。

　　1)建置(Build)所有的路网和地图。

　　2)储存所有档案。

　　3)将.wrl和.lvl装进.map档中。

　　记住：假如你的网格分成好几个楼层，那所有的楼层的.lvl档也都要装进.map中。

　　4)建置.map。
