范例7：进阶的物件使用方法
　　范例7：进阶的物件使用方法

　　本范例教你更进阶的物件使用以及管理方法。

　　7.0.1 检查环境

　　1)开启Editor编辑器。

　　2)选择mod ‘Tutorial07’。

　　3)在Editor Mode中打开'Tutorial-Fanciness_Jungle_Terrain.lvl'。

　　你会看到池溏上有一个瀑布。地面上有一些石头排成的道路，道路上面可以看到一些半圆型的圆圈，这些圆圈叫作徘徊点(Wander Points)，游戏中的NPC会在这些徘徊点之间闲晃行走。

　　7.1物件快捷盘

　　你会发现有些物件是你常常会用到的，如果这些物件位于较深的目录内，你就会感到不便，因为要一层一层地进入目录。幸运地，这里有一个物件快捷盘(object palette)，物件快捷盘可以放置你常用的物件，方便取用。

　　7.1.1 将物件放到快捷盘中

　　这里要教你怎么把一个satyr(怪物名)放到物件快捷盘中。

　　1)选择物件设置工具(Object Placement Tool)。

　　2)在目录视窗(Directory Pane)中，选择'records -> creature -> monster -> satyr -> am_peltast_02'。

　　3)点按在目录视窗(Directory Pane)底部的’Add to Palette’按钮。 ’am_peltast_02’就会出现在物件快捷盘中。

　　7.1.2 从物件快捷盘中取出物件，并放到平面区域编辑视窗

　　物件快捷盘的工作方式跟目录视窗一样。

　　1)选择物件快捷盘中的物件。

　　2)在平面区域编辑视窗中的地面点按滑鼠左键即可设置物件。

　　7.2群组

　　群组(Groups)就是将一群相关的物件放在一起。现在我们要示范如何让一群NPC编成一个群组，然后让他们一起往徘徊点移动。

　　7.2.1产生群组

　　1)选择群组工具(Group Tool)。你会看到右边的群组列表视窗(Group List Pane)中已经有一个群组叫作”Wander Points”。(译：我并没有看到任何群组)

　　2)在群组列表视窗(Group List Pane)中按下’New’按钮。

　　3)在群组属性视窗中，把Name改成”The Wanderers”。

　　4)在群组属性视窗中，把Type改成”Npc Wanderers”。

　　5)接着，再产生一个新的群组，Name为”Wander Here”，Type为’’wander points”。

　　第一个群组包含所有的NPC；第二个群组将这些NPC连结到他们要前往的徘徊点。

　　7.2.2连结群组

　　1)在”Wander Here”群组被选择的情况下，点按画面上的两个球体—称为边界体(bounding volumes)，出现红色的方框，代表它们已经是群组的一部份了。

　　2)选择”The Wanderers”群组，点按画面上的三个NPC，出现红色的方框代表他们被连结在一起了(同一群组)。 　

　　3)打勾”Link Mode”，点按两个球体中间的那个黑点，出现一个大的箭头，这就代表NPC们所要前往的俳徊点。

　　这些被群组在一起的NPC们会在这两个俳徊点间行走。通常，你需要设置至少两个俳徊点，并且将它们设给某些NPC。

　　7.3声音

　　要在游戏中产生声音，那就必须设置声音物件(sound object)。当主角愈靠近声音物件，声音就会愈大。

　　7.3.1产生声音发射体

　　1)选择物件设置工具(Object Placement Tool)。

　　2)在目录视窗中，选择’ records ->sounds -> soundobjects -> waterfall01’。

　　3)将此物件放到瀑布的下方。你会看到一根绿色的柱子，当主角愈靠近它，声音就会愈大。

　　7.4重生点

　　重生点(respawn point)就是主角死亡后出现的地方。主角必须靠近重生点物件

　　(例如：复活喷泉)才能启用该重生点。当主角死亡后，他会出现在最近一次他所启用的重生点。

　　7.4.1产生重生点

　　1)在目录视窗中，选择’ records -> item -> shrines -> respawntemplegreece01’。

　　2)在地面上点按滑鼠左键。

　　3)选择群组工具(Group Tool)。

　　4)产生一个新的群组。 　　

　　5)将群组的Name改为”Respawn Shrines”。

　　6)将群组的Type设为”RespawnShrine”。

　　7)将步骤2所产生的重生物件加到群组中。

　　现在重生物件已能正常地在游戏中发挥它的功能。通常，你要先建立自己的平面区域，并且在设置好一切的东西之后，再来设置重生点。

　　7.5宝箱

　　7.5.1产生宝箱

　　当主角打开宝箱(treasure chest)可以得到各种物品(item)。

　　1)选择’ records -> item -> containers -> greece -> monsterchest_epic_01a’。

　　2)在地图上点按滑鼠左键。

　　3)储存并重建地图。

　　4)在游戏中打开此宝箱。
