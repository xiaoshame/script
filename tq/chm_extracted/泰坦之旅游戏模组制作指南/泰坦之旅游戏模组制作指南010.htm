范例9：建立触发器
　　范例9：建立触发器

　　任务(Quest)被放在quest档案中。一个quest档案会包含许多触发器(trigger)，触发器用来控制任务的流程。每一个触发器会包含许多的状况(condition)和行动(action)，当触发器的所有状况被满足后，行动就会被执行。在此范例中，我们要设定一个触发器，内容是当主角进入某个区域后，他会得到10点经验值。

　　9.1触发器

　　9.1.1 任务档案

　　这个触发器会包含一部份之前已存在的任务。

　　1)打开Quest Editor。

　　2)到’File -> Select Mod…’选择’Tutorial09’。

　　3)到’File->Open…’开启工作目录中的'CustomMaps -> Tutorial09 -> source -> Quests -> Tutorial-Experience_Trigger.qst'。

　　点按Files视窗(Pane)中的’Experience Trigger’，你会看到一个”Only One Setp”。

　　9.1.2 产生触发器

　　1)选择Script Data视窗中的’Only One Step’。

　　2)在工具列中按’Create New Trigger’按钮。

　　在’Only One Step’的底下就会出现一个新的触发器。

　　3)选择刚建立的触发器。

　　4)你可以看到在营幕下面方的属性视窗(Properties Pane)中，出现属性清单。

　　5)将新的触发器的Name改成”The Trigger”。

　　9.2状况

　　一个触发器会包含许多的状况(condition)和行动(action)，当触发器的所有状况被满足后，行动就会被执行。我们先来设置触发器的状况，当主角进入一个特定区域后，状况会被启动。

　　1)点按刚建立的’The trigger’下方的’Conditions’。

　　2)按’Create New Condition’按钮。

　　出现一个Add New Condition视窗，里面有各种状况可以选择。

　　3)选择’Enter Bounding Volume’。

　　4)按下’OK’按钮。

　　当主角进入一个边界体(bounding volume)时，状况会被启动(满足)，先来设置边界体。

　　5)在Scrip Data视窗中，选择’Enter Bounding Volume’。

　　在下方的属性视窗中，有一个BaseDatabaseRecord属性，这就是设置边界体的地方。

　　6)点按BaseDatabaseRecord属性的栏位。

　　你可以手动输入路径，也可以用旁边的’…’按钮来选择。只要先在右边的资产选择视窗(Asset Chooser Pane)中，选择你要的项目，再按这个’…’按钮，它就会自动将路径填入。

　　7)在资产选择视窗(Asset Chooser Pane)中，选择’Database -> triggers -> Tutorial-Sphere_OF_Experience.dbr’。

　　8)按下BaseDatabaseRecord属性的栏位旁的’…’按钮。

　　Tutorial-Sphere_OF_Experience的路径已经设好了。当主角进入这个边界体后，状况会被启动(满足)，接着我们要设置行动(action)。

　　9.3行动

　　9.3.1 产生行动

　　1) 选择触发器下方的’Actions’。

　　2)按下工具列的’Create New Action’按钮。

　　出现一个’Add New Action’视窗，它列出了所有可用的行动类型。

　　3)选择’Give Player N,N,N Experience’。

　　4)按’OK’。

　　现在这个触发器设定为：当主角进入这个区域后，可以得到经验值。现在来设定经验值的数目。

　　5)选择刚建立的’Give Player N,N,N Experience’。

　　在属性视窗中，你可以看到三个属性栏位：

　　ExperienceEpic、

　　ExperienceLegendary、

　　ExperienceNormal。它代表主角在各种不同游戏难度

　　(Epic、Legendary、Normal)中，会得到的经验值数目。

　　6)你可以依个人喜好填入数字，我填100。

　　9.4储存并建置任务

　　9.4.1 储存并建置任务档案

　　现在我们已经产生了任务(quest)，现在我们要储存并建置它。

　　1)在选单中点按’File -> Save’，储存完成后，接着要建置它。

　　2)打开Art Manager。

　　3)选择Mod’Tutorial09’。

　　4)点按建置(Build)。

　　5)打开Editor编辑器，选择Tutorial09里面maps资料夹中的.wrl档案。

　　6)在选单中，点按’Quests -> Select Files…’，按下’Add’按钮并选择’ Tutorial-Experience_Trigger.qst’。

　　7)储存这个平面区域后，回到Art Manager中，再次执行建置(build)。

　　9.4.2 测试你的触发器

　　1)进入游戏中。

　　2)选择’ Tutorial09 ~ Tutorial-Sphere_of_Experience.map’地图。

　　3)让主角进入地图中间圆型的地方。如果状况满足了，则你会得到经验值点数。

　　(译：你要在地图中设立一个出生点(spawn point)，才能够进入游戏中。)
