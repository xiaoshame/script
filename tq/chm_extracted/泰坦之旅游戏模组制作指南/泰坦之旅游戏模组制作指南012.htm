范例11：使用新的资料库
　　范例11：使用新的资料库

　　在TitanQuest中的每个物件都有一笔资料库记录(database record)。一笔资料库记录(database record)就是一系列的资料，用来决定此物件的外观与行为。

　　在此范例中，我们要产生一只巨大的乌龟，这只乌龟和一般的乌龟外型一样，但是它是一般乌龟的五倍大。

　　在Editor与Quest Editor编辑器中，你可以看到所有预设的资料库记录，你可以用它来设置物件、怪物、NPC、建筑物等等的东西。有时候你会想要修改它，底下将介绍如何将记录(records)汇到你的模组中。(译：我们要使用范例10所建立的模组)

　　11.1.1 汇入资料库记录

　　你可以将Titan Quest预设的资料库记录汇入到你的模组中以便修改或是产生新的记录。在你的模组中的资料库记录会取代预设的资料库记录。

　　1)在Art Manager中，打开’Mod -> Select -> test1’ (假设test1是你在范例10所建立的模组名称)。

　　2)选择DataBase标签页，执行’Mod -> Import Record…’。这里可以浏览并选择一个你要汇入的记录

　　3)选择’records -> creature -> monster -> giantturtle -> am_snapper_08.dbr’并按下’OK’。

　　在DataBase标签页中你可以看到我们刚才汇入的纪录。

　　此汇入的纪录(am_snapper_08.dbr)是预设资料库纪录的复本，我们可以任意地修改它，而不会影响到原始资料库纪录中的资料。我们也可以改变它的目录位置。

　　4)在records上点按滑鼠右键选择’Create Directory…’。出现一个视窗输入’MyMonster’即可建立一个叫MyMonster的资料夹。我们要将’am_sanpper_08.dbr’搬到MyMonster资料夹方便管理。

　　5)在am_snapper_08.dbr上点按滑鼠右键选择’Copy’。

　　6)选择MyMonster资料夹，将刚才复制(copy)的物件贴(Paste)在右边的视窗中。

　　7)将MyMonster资料夹中的’am_snapper_08.dbr’改名(rename)成’GiantTurtle.dbr’。

　　我们要的物件已经放置好并改成容易记的名字了，原本records下的creature资料夹(包含里面的资料)就可以删除了。(注：要从最内部资料删起)

　　11.1.2 编辑资料库记录

　　现在我们有一个新的物件(GiantTurtle.dbr)了，但是除了名字不同外，它跟原始的那个物件有何不同？我们之前说过要让它变成五倍大，所以我们要修改这个物件的属性资料。

　　1)滑鼠双击’GiantTurtle.dbr’ (或按右键选择’ Edit…’)进入编辑记录视窗(Editing Record window)。编辑记录视窗有左边是阶级视窗(Hierarchy Pane)，用来显示此物件的属性阶级关系；右边是属性视窗(Properties Pane)，用来显示属性资料。

　　2)我们要改的是All Groups -> Actor Variables中的scale与actorRadius变数。

　　scale决定此物件的大小；actorRadius决定此物件跟别的物件接触的距离范围。

　　3)在阶级视窗(Hierarchy Pane)中选择All Groups -> Actor Variables类别。

　　4)将scale属性值改成5。

　　5)将actorRadius属性值变成5。

　　6)储存并关闭编辑记录视窗(Editing Record window)。

　　11.1.3 建置资料库记录

　　现在我们已经改变了资料库记录中的资料值，现在要将这些新的资料值建置到资料库中，以便游戏来读取。

　　1)选择’Test1\database’资料夹。

　　2)点按滑鼠右键选择’Build’。

　　现在新的资料库记录已经建置到资料库中，你可以在Editor编辑器中使用这个新的物件了。
