泰坦设置文件优化方法
　　泰坦设置文件优化方法(双核必备)

　　设置文件的位置　: C:\... ...\My Documents\My Games\Titan Quest - Immortal Throne\Settings

　　文件名 :　　　　　　　　Options.txt

　　打开方法 :　　　　　　双击

　　文件内容 :

　　networkSpeed　　　　　　　= medium

　　networkMTU　　　　　　　　= 1400

　　displayDamage　　　　　　 = false

　　quickBuy　　　　　　　　　= true

　　itemComparison　　　　　　= true

　　extraRollovers　　　　　　= true

　　lockItemPickup　　　　　　= true

　　showMonsterLevelOnRollover = false

　　displayHealthManaNumbers　= true

　　mapZoom　　　　　　　　　 = 0.5

　　importedCharacters　　　　= false

　　textureQuality　　　　　　= high

　　shadowQuality　　　　　　 = high

　　shadows　　　　　　　　　 = true

　　reflectionQuality　　　　 = high

　　detailLevel　　　　　　　 = high

　　resolution　　　　　　　　= 1920 1200

　　antiAliasing　　　　　　　= false

　　fullscreen　　　　　　　　= true

　　syncToRefresh　　　　　　 = true

　　tripleBuffer　　　　　　　= false

　　cameraShake　　　　　　　 = true

　　detailObjects　　　　　　 = true

　　advancedEffects　　　　　 = true

　　brightness　　　　　　　　= 0.5

　　contrast　　　　　　　　　= 0.5

　　gamma　　　　　　　　　　 = 0.5

　　masterVolume　　　　　　　= 0.99

　　musicVolume　　　　　　　 = 0.99

　　effectsVolume　　　　　　 = 0.99

　　dialogVolume　　　　　　　= 0.99

　　ambientFrequency　　　　　= high

　　rockOn　　　　　　　　　　= false

　　speakerType　　　　　　　 = high

　　device　　　　　　　　　　= Direct3D

　　language　　　　　　　　　= "Chinese"

　　datapath　　　　　　　　　= ""

　　forceSingleProcessorMode　= true

　　skipCompatibilityChecks　 = false

　　useArchives　　　　　　　 = true

　　这里的设置大多数可以在游戏中的设置修改.介绍几个常用的不太好修改的.

　　1.双核支持 forceSingleProcessorMode　= true 意思是 强制单处理器模式 。

　　默认为 true 改为 forceSingleProcessorMode　= false 能提高大约3~6fps

　　2.驱动修改 device　　　　　　　　　　= Direct3D 意思是 驱动程序。

　　默认为Direct3D 改为 device　　　　　　　　　　= OpenGL 对支持OpenGL好于

　　Direct3D的显卡有效

　　3.解析度修改 resolution　　　　　　　　= 1920 1200 意思是 解析度。

　　对一些屏幕是宽屏，但显示模式中没有相应的宽屏解析度时，可在这直接修改为相应解析度。
