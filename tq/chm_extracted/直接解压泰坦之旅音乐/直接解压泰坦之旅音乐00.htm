直接解压泰坦之旅音乐
　　直接解压泰坦之旅音乐的方法~~很简单的~~　

　　近来发现很多朋友想要泰坦之旅里面的音乐。现在就和大家一起分享一下方法。

　　其实里面那首女的唱的 欧 欧 ~~ 的 很好听啊 o(∩_∩)o...哈哈

　　那首歌叫做 When Gods Fall，是Scott B. Morton主唱的

　　有兴趣的朋友可以去baidu一下

　　进入正题吧

　　其实不用其他任何工具，用泰坦之旅自带的工具就可以解出音乐了。

　　以我自己的机器示范一下：

　　1.首先 点击开始--运行--输入cmd 打开命令提示符

　　我的泰坦之旅是装在F:\THQ

　　所以先在在命令提示符下输入 F: （即：F然后冒号），在其他盘符的朋友以此　

　　类推

　　2.接着输入 CD THQ 进入泰坦之旅目录

　　这时候你可以看到有一个文件叫做 ArchiveTool.exe ，仔细找找

　　接着进入Audio文件夹（就在泰坦之旅文件夹内），把music.arc复制出来，复　

　　制到和ArchiveTool.exe同样的目录

　　3.接着就是关键了 输入 ArchiveTool.exe music.arc -extract f:\tqmusic

　　这里的前提是我已经在F盘建了一个文件夹叫做tqmusic的

　　我的回显是这个样子的

　　F:\THQ\Titan Quest>ArchiveTool.exe music.arc -extract f:\tqmusic

　　(1 / 398) bosses/egyptbossgenericloop01.wav

　　(2 / 398) bosses/egyptbossgenericloop02.wav

　　(3 / 398) bosses/egypttelkinemainloop.wav

　　(4 / 398) bosses/greekbossgenericintro01.wav

　　(5 / 398) bosses/greekbossgenericloop01.wav

　　...

　　耐心等待一会儿就可以全部解出来了

　　接着 Enjoy it！~~
